# 暖手宝选购清单 🧤

拼多多暖手宝的实拍汇总页：13 款商品，含**卖家图 + 真实买家返图 + 直达链接 + 参数简介**，手机端友好。

👉 在线看：<https://mzil-1.github.io/nuanshoubao/>

## 内容

| 分组 | 数量 | 说明 |
| --- | --- | --- |
| 截图同款 | 7 | 按用户提供的 7 张拼多多截图逐个比对找到的链接（②⑥⑦ 为同款，①③④⑤ 为同系列对应款） |
| 额外推荐 | 6 | 按销量 + 评价数筛出的高性价比款 |

页面里每张卡片包含：

- 商品卖家主图
- 与原始截图的对照缩略图（截图同款）
- 券后价 / 店铺销量 / 参数标签 / 商品简介
- 买家评价里带图的原图（可点开放大）
- 直达拼多多商品详情页的链接

## 技术说明

- 纯静态单页，无框架、无依赖、无外部请求，图片全部本地化
- 移动优先：`viewport-fit=cover` 适配刘海屏，图片懒加载，买家图横向滑动
- 顶部「截图同款 / 额外推荐」筛选，点击任意图片全屏查看
- 直接打开 `index.html` 即可离线浏览
